# Upgrade to V1.5.5.1

1. Close the existing Lottery AI window.
2. Extract the V1.5.5.1 ZIP to a new folder.
3. Copy your existing `data` folder into the new V1.5.5.1 folder if your data is stored beside the application. If you use an external data folder, no move is required.
4. Run `START_LOTTERY_AI.bat`.
5. Click **Update Data Now** once and confirm that the LOTTO MAX upper-right card shows the next draw date and next jackpot.

The prediction model, frozen predictions, scoring, menus, and historical database schema are unchanged by this hotfix.
